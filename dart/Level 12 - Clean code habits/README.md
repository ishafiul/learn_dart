# Level 12 - Clean code habits (ongoing)

Part of the **Professional Engineering Track**. These guides are meant to be revisited as you write real code.

## Goals

- Name types and members clearly for Dart readers.
- Keep functions small and abstractions earned.
- Lay out packages with obvious homes for models, services, repositories, and utilities.
- Use formatter, analyzer, and doc comments as defaults, not chores.
